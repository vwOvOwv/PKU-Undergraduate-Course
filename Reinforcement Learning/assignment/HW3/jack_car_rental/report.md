# HW3 实验报告

## 策略评估和策略迭代

策略评估和策略迭代与HW2类似，这里基于动作价值函数 $Q(s,a)$。

根据Bellman方程：

$$Q(s,a) = \sum_{s'\in\mathcal S,r\in\mathcal R}p(s',r|s,a)[r+\gamma Q(s',\pi(s'))]$$

$$\pi'(s) = \arg\max_{a\in\mathcal A}Q(s,a)$$

## 性能优化

可以将策略评估中$Q(s,a)$的迭代计算分解为两部分。

第一部分：给定一天租赁结束后剩余的车辆数量，根据还车数量的概率分布计算第二天租赁开始前可用的车辆数量，并在此基础上计算第二天的平均动作价值。即从状态 $s_{\mathrm{mid}}$ 转移到状态 $s'$ ，这里 $s_{\mathrm{mid}}$ 为一天租赁结束后两个位置的车辆数量。

第二部分：给定每天租赁开始前可用的车辆数量，根据租赁数量的概率分布计算每天租赁结束后剩余的车辆数量。即从状态 $s$ 转移到状态 $s_{\mathrm{mid}}$ 。结合第一部分的结果，即可计算从状态 $s$ 转移到状态 $s'$ 的动作价值。

通过引入中间状态 $s_{\mathrm{mid}}$ ，可以显著加快运行速度。可以这样优化的原因在于一旦 $s_{\mathrm{mid}}$ 被确定，第二天的动作价值就只依赖于 $s_{\mathrm{mid}}$ ，而与 $s$ 无关了。

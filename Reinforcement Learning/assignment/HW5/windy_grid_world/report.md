# HW5 实验报告

对比了SARSA（on-policy TD learning）和Q-learning（off-policy TD learning）。
前者使用 $t$ 时刻的 $Q$ 计算 $t+1$ 时刻的动作，后者使用 $t+1$ 时刻的 $Q$ 计算 $t+1$ 时刻的动作。

## SARSA

输出结果如下：
```txt
Sarsa result:
(0,3)->(1,3)->(2,3)->(3,3)->(3,5)->(4,6)->(5,6)->(6,6)->(7,6)->(8,6)->(9,6)->(9,5)->(9,4)->(9,3)->(9,2)->(8,2)->(7,3).
Episode length: 16
```
小于17步，符合预期。

## Q-learning

输出结果如下：
```txt
Q learning result:
(0,3)->(1,3)->(2,3)->(3,3)->(4,4)->(5,5)->(6,6)->(7,6)->(8,6)->(9,6)->(9,5)->(9,4)->(9,3)->(9,2)->(8,2)->(7,3).
Episode length: 15
```
与教材结果相同，符合预期。

# 编译原理课程实践报告：基于C++的SysY编译器实现

信息科学技术学院 2100012289 刘沛雨

## 一、编译器概述

### 1.1 基本功能

本编译器基本具备如下功能：
1. 支持 `SysY` 子集的函数、表达式、常量/变量与控制流（`if`/`else`、`while`、`break`/`continue`）。
2. 支持全局/局部变量与数组定义、初始化，支持函数调用与内置库函数。
3. 可生成中间 `IR` 并输出 `RISC-V` 汇编。

### 1.2 主要特点

本编译器的主要特点是**分层架构清晰**、**短路求值正确**、**数组处理完备**。分层架构清晰体现在从 `AST`→`IR`→`RISC-V` 的流水线式实现；短路求值通过生成分支与中间块保证逻辑语义；数组处理覆盖多维数组、初始化展开与指针参数传递。

## 二、编译器设计

### 2.1 主要模块组成

编译器由 5 个主要模块组成：词法/语法分析负责生成 `AST`；`AST` 负责语义驱动的 `IR` 生成；符号表模块维护作用域与常量信息；`IR` 模块提供指令与基本块抽象；后端将 `IR` 映射为 `RISC-V` 汇编。

### 2.2 主要数据结构

本编译器最核心的数据结构是 `AST` 与 `IR`。`AST` 由一组继承 `BaseAST` 的节点构成，每个节点能生成对应 `IR` 或在常量表达式阶段返回计算值。

```c
class BaseAST {
public:
  virtual void generate_ir(ProgramIR* ir) const = 0;
  virtual int calculate_val() const;
};
```

`IR` 采用 `Program`/`Function`/`BasicBlock`/`Instruction` 的层级组织，指令包括 `alloc`/`load`/`store`/`branch`/`jump`/`call`/`getptr`/`getelemptr` 等，便于控制流与数组寻址建模。

```c
class ProgramIR {
  std::vector<std::unique_ptr<FunctionIR>> funcs;
  std::vector<std::unique_ptr<GlobalAllocIR>> globals;
};
```

此外，符号表以“作用域栈 + 唯一命名”的方式解决重名与作用域问题，同时保存常量值、数组维度等信息，辅助常量折叠与数组寻址。

```c
struct SymbolInfo {
  bool is_const;
  int const_val;
  std::string var_name;
  bool is_array;
  bool is_pointer;
  std::vector<int> dims;
};
```

### 2.3 主要设计考虑及算法选择

#### 2.3.1 符号表的设计考虑
采用作用域栈结构，进入/退出语句块时压栈/出栈，查找时从内向外匹配。对局部变量使用“名字+计数器”的唯一化策略，避免 `SSA` 名冲突；全局变量保持原名。符号表同时保存常量值、数组维度与指针标志，便于常量表达式计算与数组寻址。

#### 2.3.2 寄存器分配策略
未做复杂寄存器分配，采用“全部落栈”的策略：为每个中间值分配栈槽（`val_offset_map`），局部变量/数组也分配栈槽（`var_offset_map`），`RISC-V` 生成时使用 `t0`/`t1` 暂存并通过 `lw`/`sw` 访问。函数参数优先放入 `a0`–`a7`，超出部分按 ABI 放入栈上。

#### 2.3.3 采用的优化策略
没有做全局优化，主要在常量表达式与数组初始化阶段做“编译期计算/展开”，将常量求值结果直接写入全局或局部初始化。

#### 2.3.4 其它补充设计考虑
逻辑与/或采用显式控制流实现短路求值；`if`/`while` 通过显式 `BasicBlock` 与 `branch`/`jump` 建模；`break`/`continue` 用循环入口/结束栈记录跳转目标；函数末尾补齐默认 `return`，保证控制流完整。

## 三、编译器实现

### 3.1 各阶段编码细节

#### Lv3. 表达式
实现了表达式 `AST` 递归下降生成 `IR`，支持算术/关系/逻辑/一元运算，逻辑与/或通过基本块实现短路语义。

#### Lv4. 常量和变量
加入符号表与常量求值（`calculate_val`），支持 `const`/`var` 的声明与初始化，区分全局与局部变量，生成 `alloc`/`load`/`store` 指令。

#### Lv5. 语句块和作用域
`Block` 节点进入/退出作用域，解决嵌套块变量遮蔽；局部变量唯一命名避免重名冲突。

#### Lv6. if语句
用 `then`/`else`/`end` 三个块构造控制流，设置 `bison` 的 `else` 绑定优先级解决悬空 `else`；根据分支末尾是否已终结决定是否补跳转。

#### Lv7. while语句
构建 `entry`/`body`/`end` 三块，`entry` 进行条件判断；维护 `loop_entry_stack`/`loop_end_stack` 处理 `break`/`continue`；在 `break`/`continue` 后生成 `dead` block 防止继续写入已终止块。

#### Lv8. 函数和全局变量
支持函数定义、参数列表与调用；函数入口分配参数槽并保存传参；加入内置库函数声明表与调用处理；全局变量通过 `GlobalAllocIR` 输出到 `.data`。

#### Lv9. 数组
支持多维数组与数组参数：维度记录在符号表中，寻址时计算 `stride` 并使用 `getelemptr`/`getptr`；数组初始化通过递归展开和补零完成；支持局部数组逐元素 `store`。

### 3.2 工具软件介绍
1. `flex/bison`：完成 `SysY` 的词法与语法分析，生成 `AST`。
2. `标准 C++ STL`：用于智能指针、容器和字符串等基础设施。

### 3.3 测试情况说明
主要依赖课程自带测试样例进行验证，未进行系统化的额外测试用例构造。

## 四、实习总结

### 4.1 收获和体会
通过实现 `AST`→`IR`→`RISC-V` 的全流程，更直观地理解了编译器前后端分工与控制流建模方法，尤其是短路求值与数组寻址的实现细节。

### 4.2 学习过程中的难点，以及对实习过程和内容的建议
数组初始化展开与多维 `stride` 计算较为繁琐，易出错；建议配套更多分层样例与调试提示，帮助定位初始化或地址计算问题。

### 4.3 对老师讲解内容与方式的建议
课程节奏整体合理，难度适中。建议增加可视化和伪代码，帮助理解和建立直觉。

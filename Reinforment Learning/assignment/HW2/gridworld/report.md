# HW2 实验报告

## 策略评估（policy evaluation）

根据Bellman方程进行迭代：

$$v_\pi(s) = \sum_{a\in\mathcal A}\pi(a|s)\sum_{s'\in\mathcal S,r\in\mathcal R}p(s',r|s,a)[r+\gamma v_\pi(s')]$$

对于该环境和随机策略，$p(s',r|s,a)$恒为1（确定性的环境），$\pi(a|s)=0.25$。

得到的价值函数$v_\pi$为

```txt
3.31	8.79	4.43	5.32	1.49
1.52	2.99	2.25	1.91	0.55
0.05	0.74	0.67	0.36	-0.40
-0.97	-0.43	-0.35	-0.58	-1.18
-1.86	-1.34	-1.23	-1.42	-1.97
```

和答案基本一致。

此外还简单尝试了TD算法，通过与环境多次交互估计$v_\pi$，结果为
```txt
3.39    8.80    4.48    5.34    1.51
1.57    3.06    2.33    2.00    0.58
0.11    0.82    0.70    0.39    -0.38
-0.93   -0.41   -0.30   -0.56   -1.18
-1.85   -1.33   -1.18   -1.41   -1.93
```
结果整体与直接计算得到的结果差不多，但是需要多次迭代。
